## B 機 平飛上下擺盪 (飛控 BIN)
![B 機 pitch 擺盪](pitch_osc_B.png)

- 整段 AUTO 平飛都有: 週期 3.3~3.7 s (0.29 Hz), pitch ±4~6°, 高度 ±1~2 m (最大 ±4 m); DIVE 裡的 pitch 擺盪也是同一個頻率。
- 不是 TECS: 目標高度固定, 飛控要的 pitch 只擺 ±1.5~2° 且相位領先 → TECS 是在試著壓, 不是源頭。
- 不是 roll / 振動: roll 追蹤正常, VibeZ 中位數約 1 m/s²。
- 是 pitch 姿態迴路接近不穩定: 0.29 Hz 時實際角速度比要求慢約 74°, 迴路增益約 1、相位約 −164° (相位裕度只剩十幾度)。
- 增益跟 A 機一樣 (PTCH_RATE_P 0.08, PTCH2SRV_TCONST 0.5), A 機只擺 ±1.8° → 差別在 B 機本身: 舵機/連桿間隙或反應慢、空速計故障 (用推估空速, 飛得較慢)、重心/配平 (平飛平均要 +6.6% 抬頭舵)。
