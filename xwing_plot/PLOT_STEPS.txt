X-wing 飛完畫圖 — 在筆電 (Windows) 上的執行步驟
詳細說明 (每張圖看什麼、自動檢查門檻): PLOT_GUIDE.md (同一個資料夾)

畫圖的東西全部在專案的 xwing_plot 資料夾:
  x-wing_virtual\                    ← 整個專案 (飛行程式、config 都在這層)
    flight_logs\                     ← 飛機的 log (從 Orin 拷過來, 放這裡)
    xwing_plot\                      ← ★ 畫圖都在這裡做
      xwing_plot_report.py           主程式 (出全部的圖)
      xwing_plot_target_gps.py       虛擬目標 vs 真車 (主程式會自動呼叫)
      test_plot_report.py            不用飛機的測試
      car_bin\                       ← 車子的 .BIN 放這裡 (有放就自動比對)
      plot_results\                  ← 畫出來的圖 (自動產生)
※ 畫圖會用到上一層的 xwing_virtual_config.py / dive_guidance.py,
  所以要拷「整個專案」, 不能只拷 xwing_plot 資料夾.

==================================================================
 A. 第一次準備 (只做一次, 已完成可跳過)
==================================================================
1. 安裝 Python: https://www.python.org/downloads/
   安裝時勾 "Add python.exe to PATH"
   確認: 開「命令提示字元」輸入   python --version   → 出現 Python 3.x.x

2. 安裝套件 (需要網路):
   python -m pip install numpy matplotlib
   確認: python -c "import numpy, matplotlib; print('OK')"   → 出現 OK

3. 專案放到筆電桌面, 例如 C:\Users\user\Desktop\x-wing_virtual
   方法 1: GitHub → 分支 claude/kind-clarke-r77kuq → Code → Download ZIP → 解壓到桌面
   方法 2: Orin 用隨身碟拷整個 ~/catkin_ws/src/hsu_realflight_true 資料夾
           cd ~/catkin_ws/src/hsu_realflight_true
           git pull
           ls /media/$USER/                       ← 看隨身碟名稱
           cp -r ~/catkin_ws/src/hsu_realflight_true /media/$USER/<隨身碟名稱>/
           sync                                    ← 跑完再拔

4. 測試 (不用飛機):
   檔案總管打開 x-wing_virtual\xwing_plot → 點上方路徑列 → 輸入 cmd → Enter
   python test_plot_report.py --vision
   最後出現 [test] 完成 → 打開 xwing_plot\plot_results\...\run1\report.pdf


==================================================================
 B. 實飛當天 落地後
==================================================================
1. Orin Terminal 2: 輸入 q 按 Enter (結束飛行程式, log 才會存完整)

2. 飛機的 log → 筆電 x-wing_virtual\flight_logs\ (覆蓋舊的)
   Orin 終端機:
   cp -r ~/catkin_ws/src/hsu_realflight_true/flight_logs /media/$USER/<隨身碟名稱>/
   sync

3. (要比對真車才做) 車子飛控 SD 卡 → LOGS\ 裡「當天」的 .BIN
   → 放到 x-wing_virtual\xwing_plot\car_bin\ (沒有這個資料夾就自己新建)
   ※ 只放當天的 BIN, 程式會用 GPS 時間自己挑對的那一個
   ※ car_bin 裡有 BIN 就會自動比對真車, 不用另外加參數

4. 打開命令列: 檔案總管進 x-wing_virtual\xwing_plot → 路徑列輸入 cmd → Enter

5. 畫圖:

   ★ 全部一次畫 (最簡單, 建議用這個):
   python xwing_plot_report.py --all
     flight_logs 裡每一份、每一趟都畫, 最後印「總表」
     沒切 GUIDED 的 (地面測試) 會自動跳過

   只畫最新那份:
   python xwing_plot_report.py --latest

   只畫指定的幾份 (先 dir ..\flight_logs 看檔名):
   python xwing_plot_report.py xwing_virtual_XXXXXXXX_XXXXXX_flight1.csv xwing_virtual_XXXXXXXX_XXXXXX_flight2.csv
     (只打檔名就好, 程式會去 flight_logs 找)

   其他選項:
   --no-car    car_bin 裡有 BIN 也不比對真車
   --run 2     只畫第 2 趟 (同一份 log 切了好幾次 GUIDED)
   --full      地面測試 / 沒切 GUIDED: 整份畫出來

6. 看結果: x-wing_virtual\xwing_plot\plot_results\<log 檔名>\run1\
   report.pdf     ← 全部的圖, 直接開給老師看
   summary.txt    ← 時間線 + 數字 + 自動檢查
                    ✓ 正常   ⚠ 建議看的參數   ✗ 有問題
   fig1 ~ fig15   ← 單張圖 (要放投影片用這些)
   切了幾次 GUIDED 就有幾個資料夾: run1, run2, ...

==================================================================
 D. 出問題時
==================================================================
'python' 不是內部或外部命令 / 跳出 Microsoft Store
    → 安裝時沒勾 PATH: 改用 py 取代 python, 或重裝 Python 勾 PATH
No module named numpy / matplotlib
    → python -m pip install numpy matplotlib
找不到 log / 沒有 xwing_virtual_*.csv
    → flight_logs 要放在 x-wing_virtual\flight_logs (專案那層, 不是 xwing_plot 裡)
      或放成 flight_logs\flight_logs 了
can't open file 'xwing_plot_report.py'
    → 命令列不在 xwing_plot 資料夾: 重新從 xwing_plot 的路徑列輸入 cmd
這份 log 沒有任何 GUIDED 段
    → 地面測試 / 沒切 GUIDED: 加 --full
Fig 14 沒畫 (summary.txt 會寫原因)
    → car_bin 放錯天的 BIN / 放了兩個都涵蓋的 BIN / 那一趟沒進 DIVE
其他錯誤 → 把整個畫面拍下來
