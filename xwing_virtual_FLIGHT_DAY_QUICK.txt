X-wing 實飛指令 (最精簡版)      詳細: xwing_virtual_FLIGHT_DAY_COMMANDS.txt

【Terminal 1】 MAVROS, 整天開著
roslaunch mavros apm.launch

【Terminal 2】 飛控不能在 GUIDED 時才開
cd ~/catkin_ws/src/hsu_realflight_true

實飛 (DIVE 一律用方向舵控制):
python3 xwing_virtual_flight.py --moving --case flight1 2>&1 | tee console_flight1.txt

沒有雲台: 指令裡加 --no-vision

【雲台 (10/29 兩架都在起飛前/彈射時斷線, 之後再也沒回來)】
  起飛前最後一刻 + 每次切 GUIDED 前: Terminal 2 要是 VIS link=1
  出現「★RX無資料 Ns(TX=…)」或 events「★★ RX 斷線」= 對方的資料沒進來
    → 先不要切 GUIDED; 落地後【不要重開任何程式】, 先請對方查他們的程式/dmesg
  對方畫面顯示 LOCK ≠ 我們收得到資料, 以我們的 VIS link 為準
  診斷檔自動存: flight_logs/<log 名>_uart_raw.bin / _uart_health.csv / _dmesg_*.txt

【飛行中 Terminal 2】  x + Enter = 中止    q + Enter = 結束 (落地後)
                      最快中止: 飛手撥 FBWA
【重飛】 不用重開程式: 切出 GUIDED → 下一圈到 WP3 再切 GUIDED = 新的一趟
        出現「不啟動任務」= 位置/高度/方向不對 → 切回 AUTO, 下一圈到 WP3 再切

【落地後】
python3 xwing_gimbal_mode_test.py   → 按 s → 按 q    (雲台回追蹤)
log: flight_logs/  +  console_*.txt  +  飛控 .BIN
