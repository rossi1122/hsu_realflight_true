------------------------------------------------------------------
[ ] 6. 整機掛機 (不接相機)
------------------------------------------------------------------
先在 Mission Planner 讀飛機目前位置 LAT, LON
虛擬目標起點 = (LAT + 0.0054, LON)
  例: 實驗室 22.9956196,120.2235073 → --start 23.0010196,120.2235073

Terminal 1 的 MAVROS 保持開著, Terminal 2:

    python3 xwing_virtual_flight.py --moving --bench --ground-test \
            --start <LAT+0.0054>,<LON> --tgt-heading 180 \
            --no-vision --case bench_F1 2>&1 | tee console_bench_F1.txt

開機訊息要看到:
  [ ] PTCH_LIM_MIN_DEG=-40° OK
  [ ] AIRSPEED_MAX=60 m/s OK
  [ ] GUIDED_P=5000 → 43002 航向控制可用
  [ ] 串流率設定完成 6/6

操作:
  1) 等畫面每秒印 [SEARCH  ] ... g=0
  2) 切 GUIDED
  3) 約 18.5 秒後出現 MODE: SEARCH → PRE_DIVE
     [ ] 兩片 V 尾往「同一個方向」動 (有差動 = 不能飛)
  4) 約 45 秒後自動 ABORT → DONE (掛機正常現象)
  5) 切回 MANUAL → Terminal 2 輸入 q 按 Enter

傳給 Claude 確認:
  flight_logs/xwing_virtual_<時間>_bench_F1.csv
  flight_logs/xwing_virtual_<時間>_bench_F1_events.txt
  console_bench_F1.txt

  - Terminal 2 輸入 q 按 Enter
  - 雲台解除鎖定: python3 xwing_gimbal_mode_test.py → 1 → q
