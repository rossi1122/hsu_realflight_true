 E. 開程式 (起飛前就開好)
==================================================================
Terminal 1:

Terminal 2 (到專案資料夾):
    cd ~/catkin_ws/src/hsu_realflight_true-claude-kind-clarke-r77kuq   (換成你的路徑)

  第一趟 — 版本 B (DIVE 不打方向舵):
    python3 xwing_virtual_flight.py --moving --dive-hold-heading --case flight1_B \
            2>&1 | tee console_flight1_B.txt

  第二趟 — 版本 A (DIVE 用方向舵 PID):
    python3 xwing_virtual_flight.py --moving --case flight2_A \
            2>&1 | tee console_flight2_A.txt

  ★ --case 照抄上面 (flight1_B / flight2_A), log 檔名就看得出版本
  當天沒接雲台: 指令後面加 --no-vision
  ★ 實飛【不要】加: --bench  --bench-dive  --ground-test  --start  --tgt-heading

  Permission denied / 串口開不了 / VIS link=0 一直不變 / 模式鍵 OFF

  (我們的程式沒打方向舵; 實飛在 WP3 切, 機頭已朝南, 不會這樣)


==================================================================
 G. 飛行
==================================================================
1) 起飛 → AUTO 爬到 240 m → 先繞一圈不切 GUIDED
   確認: 高度 ~240 m、空速 ~30 m/s、轉彎後對正往南、VIS link=1

2) 飛機通過 WP2 轉彎點 → 地面站喊「開」, 車子起步
3) 飛到 WP3 → 地面站 Set Mode GUIDED (事先選好, 到點按一下; 延遲 0.5~1 s 可稍提早)
   ★ 不要晚切: SEARCH 只有約 9.9 s, 晚 1 s 就少 1 s

4) 之後全自動, 畫面依序 (時間 = 切 GUIDED 後):
     0 s     ★ GUIDED 上升沿 — 種點 + ARM
             切 GUIDED 時離目標起點 約 600 m       (★ 出現「> 3 km」= 切錯地方, 這趟不會俯衝)
             雲台狀態 → SEARCH: 模式鍵 '1'
     ≤0.3 s  雲台回報模式 '1' 已確認              (雲台追蹤)
     ~10 s   ★★ MODE: SEARCH → PRE_DIVE         (推頭)
             雲台狀態 → PRE_DIVE: 模式鍵 '2'
     ~10 s   雲台回報模式 '2' 已確認
     ≤11 s   ★ 雲台鎖定到位 pitch=-29.x°        (地面實測: 相機1 1.0 s, 相機2 0.5 s)
     ~11.3 s ★★ MODE: PRE_DIVE → DIVE           (30° 俯衝, 空速 32→46 m/s)
     ~16.8 s ★★ MODE: DIVE → PULLOUT            (約 120 m 拉平)
     ~17.3 s ★★ MODE: PULLOUT → DONE            (平飛往南, 最低約 105 m)

5) 看到 PULLOUT → DONE → 地面站切回 AUTO (爬回 240 m)

6) 要再飛一趟:
   同一個版本 → 不用重開程式, 下一圈到 WP3 再切 GUIDED 就是新的一趟
                (目標重新從 WP4 出發; log 的 run 欄位 = 第幾趟)
   換版本 (B → A) → 在 AUTO 繞圈時 Terminal 2 輸入 q → 打版本 A 的指令重開 →
                看開機訊息 → 下一圈到 WP3 再切 GUIDED

★ 切換規則 (程式自動處理):
   · 任何時候都可以切出 GUIDED, 飛控立刻不聽程式的
   · 切出超過 1 s → 這一趟結束並重置, 畫面出現「任務重置 — 下次撥 GUIDED = 第 N 趟」
   · 再切 GUIDED → 新的一趟從頭開始
   · 切 GUIDED 時離 WP4 < 450 m, 或已經飛過 WP4 → 出現「不啟動任務」,
     程式只保持航向直飛, 不會推頭 → 切回 AUTO, 下一圈到 WP3 再切

中止 (中止後不用重開程式, 下一圈到 WP3 再切 GUIDED 即可重飛):
  ★ 最快: 飛手模式開關撥到 FBWA (要跟目前位置不同才會切)
  地面站: Mission Planner 切 AUTO / FBWA
  機載: Terminal 2 輸入 x 按 Enter → 拉起 2.5 s 後放手
  雲台中斷 / 模式鍵沒確認 → 不用處理 (只記錄, 不影響控制)
